Textures must go into this directory, copied from Geometry Dash. The following textures are not provided and are required:

- bigFont-hd.png
- GJ_GameSheet.png
- GJ_GameSheet02.png
- GJ_GameSheet03.png
- GJ_GameSheet04.png
- GJ_GameSheetIcons.png
- GJ_GameSheetGlow.png
- GJ_LaunchSheet.png
- ground.png
- square01_001.png
- square02_001.png

You can obtain these textures from Geometry Dash by looking in the `Resources` directory of the Geometry Dash installation
directory. For instance, if you installed Geometry Dash via Steam, these files would be in:

    .../steam/steamapps/common/Geometry Dash/Resources
